# ESP32 智能环境控制系统-创新工程实践项目
## 1. 项目概述

本项目基于 **ESP32 DevKit V1** 开发板，构建了一个集环境感知、智能控制与人机交互于一体的微型环境控制系统。系统主要应用于宠物饲养箱、精密仪器柜等恒温恒湿场景。

**核心功能：**
*   **智能温控**：采用 Fuzzy-PID (模糊PID) 算法，实现温度的精准恒定。
*   **自动补光**：根据环境光强 (LDR) 自动调节补光灯亮度。
*   **直观交互**：OLED 实时显示状态，支持红外遥控器 (NEC 协议) 进行参数设定。
*   **非阻塞架构**：基于时间片轮询调度，确保多任务并行处理流畅无卡顿。

## 3. 软件安装与部署

本项目基于 **MicroPython** 开发，请确保您的 ESP32 已烧录 MicroPython 固件（建议 v1.19 或更高版本）。

### 3.1 文件结构

将以下文件上传至 ESP32 的根目录：

```text
/
├── main.py              # 主程序入口
├── fuzzy_pid.py         # 模糊 PID 算法库
├── ir_decoder.py        # 红外解码库
└── drivers/             # 硬件驱动包
    ├── __init__.py      # (可选)
    ├── ssd1306.py       # OLED 底层驱动
    ├── display.py       # 显示管理类
    ├── sensors.py       # 传感器管理类
    └── actuators.py     # 执行器管理类
```

### 3.2 运行方法

1.  使用 Thonny IDE 或 VSCode (Pymakr 插件) 连接 ESP32。
2.  打开 `main.py` 文件。
3.  点击运行按钮，或在 REPL 中输入 `import main`。
4.  观察控制台输出，应看到："系统初始化完成。等待开机指令..."。

## 4. 操作指南

### 4.1 红外遥控器按键说明

系统操作主要通过 NEC 协议红外遥控器完成。

| 按键 | 功能描述 |
| :--- | :--- |
| **POWER** | **开机 / 关机**。关机状态下系统处于低功耗待机模式。 |
| **MENU** | **切换模式**。循环切换：自动运行 (RUN) -> 设定温度 (SET TEMP) -> 设定湿度 (SET HUM)。 |
| **+ (加号)** | 增加设定值 (温度 +1°C / 湿度 +5%)。仅在设置模式下有效。 |
| **- (减号)** | 减少设定值 (温度 -1°C / 湿度 -5%)。仅在设置模式下有效。 |
| **MUTE** | **静音**。当湿度报警触发时，按下可手动关闭蜂鸣器。 |

### 4.2 OLED 界面解读

屏幕内容分为三行，信息如下：

*   **第一行 (Mode)**: 显示当前工作模式 (RUN / SET TEMP / SET HUM / OFF)。
*   **第二行 (T)**: `当前温度 / 目标温度` (例如: `T: 24.5C / 25.0C`)。
*   **第三行 (H)**: `当前湿度 / 目标湿度` (例如: `H: 55.0% / 60.0%`)。
*   **底部栏**: 显示设备状态，`HEAT` 表示加热器开启，`FAN` 表示风扇开启。

## 5. 常见问题 (FAQ)

**Q1: 红外遥控没反应？**
*   检查电池是否充足。
*   检查接收头是否连接到 GPIO 35。
*   在控制台观察是否有输出 "收到指令: ..."。如果是由于时序问题，可能需要根据具体遥控器微调 `ir_decoder.py` 中的时序参数。

**Q2: OLED 屏幕不亮？**
*   检查 SDA/SCL 是否接反 (SDA=21, SCL=22)。
*   确认 I2C 地址是否为 0x3C (默认)。

**Q3: 温湿度读数为 None？**
*   检查 DHT22 供电及上拉电阻。
*   确保 GPIO 15 接触良好。
